# My-Office-Tools
图片型PDF水印工具_离线版 1.0
Tools #1  :批量把文档/表格/PDF/图片转成「图片版 PDF」并烧录不可修改的水印。
测试通过windows\安卓\麒麟系统测试  通用功能 电脑上使用（推荐）

功能
- 支持 doc/docx/xls/xlsx/csv/pdf/jpg/jpeg/png，可多选文件 + 文件夹（递归）
- 逐页 200 DPI 栅格化 → 文字层消失，无法选中/复制/编辑
- 水印 45° 斜向平铺烧进像素，文字/字号/间距/透明度/角度/颜色全部可调
- PDF 权限密码：打开无需密码，允许打印，禁止修改/复制/注释
- 单页预览确认后再批量；输出保留目录结构；坏文件跳过并记录到 failed.csv
- 支持「仅重跑失败清单」

- 人性化改进：
- 顶部步骤条实时显示进度，每步完成自动点亮下一步
- 改任何水印参数，预览会自动刷新（无需手点）；也可以点「立即预览」手动触发
- 水印颜色可点色块或用取色器选；示例字样按真实透明度预混显示，所见即所得
- 数值填错会在旁边显示中文提示并禁用执行，不会报错崩溃
- 执行时显示「转换→加水印→写权限」阶段进度和当前文件名
- 完成后直接在结果区点「打开输出文件夹」；若有失败项可一键「查看失败清单 / 重试失败项」

- 说明
- 输出文件名为 原文件名.pdf（如 sample.docx.pdf）；同名加时间戳，不覆盖原文件
- 水印没有绝对不可去除的保证，但整页栅格化 + 权限密码可挡住常规编辑与复制
- 失败清单在输出目录的 failed.csv，修复后点「仅重跑失败清单」即可
- .doc/.xls 老式二进制格式需目标电脑有 Office/WPS 才能转换；没有时请另存为 .docx/.xlsx
